Skin pour Football Manager 27 / Skin for Football Manager 27
============================================================

FRANCAIS
--------
AVANT TOUT : tu as deja mis un autre skin, un mod d'interface ou une ancienne
version de ce skin dans FM27 ? Remets d'abord les fichiers d'origine : dans
Steam, clic droit sur FM > Proprietes > Fichiers installes > "Verifier
l'integrite des fichiers du jeu". (Si le jeu contient deja ce skin,
l'application le voit et te le redemande.)

1. Ferme FM.
2. Double-clic sur "Lancer - Launch.bat" : l'application s'ouvre.
3. Premiere fois : l'application te guide, etape par etape :
   langue, dossier du jeu (le plus souvent trouve tout seul), couleur du
   fond (facultatif), puis installation du skin. Quand elle dit "C'est
   pret", lance FM. Rien d'autre a installer (plus besoin de Python).

Linux (FM27 par Steam + Proton) : lance "Lancer - Launch.sh" au lieu du .bat
(clic droit > Executer, ou dans un terminal : sh "Lancer - Launch.sh").
Lance FM une fois avant : l'app trouve alors son dossier Proton toute seule.

Mac (FM27 par Steam) :
1. Lance Steam, mais pas FM27.
2. Double-clic sur "Lancer - Launch.command" (au premier lancement, si macOS
   refuse : clic droit > Ouvrir). Si macOS refuse encore d'ouvrir le fichier :
   Reglages Systeme > Confidentialite et securite, tout en bas de la page,
   autorise l'ouverture de "Lancer - Launch.command", entre ton mot de passe
   et continue l'installation.
3. Une fenetre du Terminal s'ouvre avec l'app : laisse-la ouverte pendant que
   tu utilises l'app. Rien a installer.
Si l'app dit que macOS bloque l'ecriture dans FM :
  a. Clique "Ouvrir les Reglages" : dans "Gestion des apps", active Terminal.
  b. macOS propose de quitter le Terminal : accepte.
  c. Relance "Lancer - Launch.command" et refais l'installation : cette fois,
     elle va jusqu'au bout.
Si seul le Terminal s'ouvre (pas l'app) apres tout ca : dans le Terminal,
cherche la ligne "L'app est ouverte (http://127.0.0.1:49417/)", copie
l'adresse (du type http://127.0.0.1:49417, le nombre peut changer chez toi)
et colle-la dans ton navigateur : l'app d'installation du skin s'ouvre.
L'app se met a jour toute seule sur Mac aussi (meme app que Windows / Linux).
Merci a Jouz et Dhragga pour les premiers tests sur Mac !

Apres une mise a jour de FM : ouvre l'application, "Installer tout le skin".
Tout enlever : dans Steam, clic droit sur FM > Proprietes > Fichiers installes >
"Verifier l'integrite des fichiers du jeu" (remet le jeu d'origine).

Le dossier "backups" garde les fichiers d'origine du jeu : ne le supprime pas.

ENGLISH
-------
FIRST: already put another skin, a UI mod or an older version of this skin
in FM27? Restore the original files first: in Steam, right-click FM >
Properties > Installed Files > "Verify integrity of game files". (If the game
already contains this skin, the app sees it and asks you again.)

1. Close FM.
2. Double-click "Lancer - Launch.bat": the app opens.
3. First time: the app guides you, step by step:
   language, game folder (usually found automatically), background colour
   (optional), then the skin install. When it says "All set", start FM.
   Nothing else to install (Python is no longer needed).

Linux (FM27 through Steam + Proton): run "Lancer - Launch.sh" instead of the
.bat (right-click > Run, or in a terminal: sh "Lancer - Launch.sh").
Start FM once before: the app then finds its Proton folder by itself.

Mac (FM27 through Steam):
1. Start Steam, but not FM27.
2. Double-click "Lancer - Launch.command" (first time, if macOS refuses:
   right-click > Open). If macOS still refuses to open the file: System
   Settings > Privacy & Security, at the very bottom of the page, allow
   "Lancer - Launch.command" to open, enter your password and carry on with
   the install.
3. A Terminal window opens with the app: keep it open while you use the app.
   Nothing to install.
If the app says macOS blocks writing into FM:
  a. Click "Open Settings": in "App Management", turn on Terminal.
  b. macOS offers to quit Terminal: accept.
  c. Start "Lancer - Launch.command" again and redo the install: this time it
     goes all the way.
If only the Terminal opens (not the app) after all that: in the Terminal,
look for the line "The app is open (http://127.0.0.1:49417/)", copy the
address (like http://127.0.0.1:49417, the number may differ for you) and
paste it into your browser: the skin's install app opens.
The app updates itself on Mac too (same app as Windows / Linux).
Thanks to Jouz and Dhragga for the first tests on Mac!

After an FM update: open the app, "Install the whole skin".
Remove everything: in Steam, right-click FM > Properties > Installed Files >
"Verify integrity of game files" (puts the original game back).

The "backups" folder keeps the original game files: do not delete it.
